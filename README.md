# A&H Legal Partners

Website and brand kit for **A&H Legal Partners**, advocates before the Lahore High Court. Partners: Azhaar Ahmad Choudhary and Haris Ali Choudhary. Chambers: 1 Turner Road, Near Lahore High Court, Lahore. Telephone 0301 7466260 (Azhaar) and 0307 2058771 (Haris). Email info@ahlegalpatners.com. Website ahlegalpatners.com.

- **Website:** React 19 + TypeScript + Vite + Tailwind CSS v4. Animation with GSAP (ScrollTrigger, SplitText) and Lenis smooth scroll. Fonts (Cormorant Garamond, Geist, Noto Nastaliq Urdu) are self-hosted via Fontsource.
- **Brand kit:** logo, business card, letterhead, long envelope, A4 envelope, court file cover, social media set and brand guidelines, all generated by one script from the same vector artwork the website uses.

## Run the website

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # type-checks, then builds to /dist
npm run preview    # serve the production build locally
```

`/dist` is plain static files and can be hosted anywhere (Vercel, Netlify, Cloudflare Pages, any web server).

## The brand kit (`brand/out`)

| Folder | What is inside |
| --- | --- |
| `AH-Legal-Partners_Brand-Guidelines.pdf` | 10-page guide: the idea, logo system, clear space, colour, typography, stationery, website, production notes |
| `logo/svg`, `logo/png` | Seal, horizontal lockup, wordmark and symbol, each in five colourways (on dark, on paper, ink, gilt, ivory). PNGs are 2400 px wide and transparent where applicable |
| `stationery/` | Print PDFs (3 mm bleed where colour reaches the edge): **business card** 88.9 x 50.8 mm, both partners, QR to the website; **letterhead** A4 (blank, plus one with a specimen letter), QR to the website; **long envelope** DL 220 x 110 mm (address side and branded side); **A4 envelope** 210 x 297 mm (address side and branded side); **file cover** 225 x 310 mm (case details front, proceedings log inside, QR to the website); plus the QR code as a vector file |
| `previews/` | PNG previews of every stationery item |
| `social/` | Profile picture (1080 px) and Facebook and LinkedIn covers |

The pieces follow the structure of the reference stationery supplied by the firm (card, envelope, A4 envelope, file cover, letterhead), redesigned in the A&H brand. Every QR code was decoded straight out of the print PDFs to confirm it scans.

### Regenerate after changing details

Edit `brand/config.py` (website, partners, numbers, address), then:

```bash
pip install -r brand/requirements.txt     # once
npm run brand                             # rebuilds everything, including the website's logo data
```

Needs Python 3.10+ and Microsoft Edge or Google Chrome (used to render the PDFs). Set `BROWSER_PATH` if yours is in a non-standard place. To rebuild one part only: `python brand/build.py logos | web | stationery | social | guidelines`.

## Before launch

1. **Register the domain and confirm its spelling.** The email (`info@ahlegalpatners.com`) and website (`ahlegalpatners.com`) are printed exactly as the firm supplied them, and every QR code points to `https://ahlegalpatners.com`. Note the spelling is "patners", without the "r" of "Partners". A registry check showed neither `ahlegalpatners.com` nor `ahlegalpartners.com` was registered at the time of writing. If the firm registers a different spelling, change `web`, `url` and `email` in `brand/config.py`, `firm.email` in `src/lib/content.ts` and the domain in `index.html`, then run `npm run brand`. Do not print the stationery until the domain is registered and the QR code has been scanned from a proof.
2. **Set up the mailbox** for the email address, and test that the QR code opens the live site.
3. **Telephone numbers** were confirmed by the firm: 0301 7466260 belongs to Azhaar Ahmad Choudhary and 0307 2058771 to Haris Ali Choudhary.
4. **Confirm the practice areas.** The ten groups cover every area listed by comparable Pakistani firms plus family, criminal and intellectual property. The partners must confirm the firm really practises each one, and the wording (for example "fees agreed in writing" and "reply within one working day") must match how the firm works. Legal advertising is regulated by the Pakistan Bar Council and Punjab Bar Council: have the final copy checked.
5. **Connect the contact form.** `submitEnquiry()` in `src/lib/enquiry.ts` only simulates sending. Point it at Formspree, Resend or your own endpoint, and throw an `Error` on failure so the form shows its error message.
6. **Replace the photography.** Images are royalty-free Unsplash placeholders referenced by id in `src/lib/content.ts`. Use the firm's own photographs when available.
7. **Add portraits** for the partners when available. The arch plates currently show the monogram letters (A and H).
8. **Check the Urdu name** (`اے اینڈ ایچ لیگل پارٹنرز`) with a native reader before printing. It is a transliteration of the English name.
9. The site's page metadata (`index.html`) already uses `https://ahlegalpatners.com`; update it if the domain changes.

## Design notes

- Palette: library green ink `#0A1512`, ivory type, paper `#F2F4EE`, one champagne gilt accent `#C6A96B`.
- Signature: the archway (a double arch with a keystone). It frames the hero photograph, the practice previews and the partner plates, it is the logo, and it appears on the stationery as a pair of corner arcs.
- Shape rule: containers are square, buttons and navigation are pills, imagery and plates are arches.
- Motion respects `prefers-reduced-motion`: visitors who opt out get a fully visible static page, with no intro and no smooth-scroll hijacking.
